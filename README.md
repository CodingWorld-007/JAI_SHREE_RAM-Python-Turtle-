# Python Turtle Animation – Jai Shree Ram

This project is a Python Turtle Graphics animation that draws a complete animation scene when the user clicks on the screen.  
I built this project from scratch while learning Python, and it helped me understand graphics, coordinates, event handling, and logic building.

## Features
- Mouse click event to start animation
- Background image rendering
- Custom text drawing using Turtle
- Shape drawing using coordinates
- Color and pen control
- Simple GUI interaction
- Event-driven programming

---

## Technologies Used
- Python
- Turtle Graphics

---

## How It Works
When the user clicks on the button area:
1. Background image appears
2. Screen background color changes
3. Turtle starts drawing the full animation
4. Shapes and text are drawn step by step using coordinates and angles

This project is based on coordinate geometry and turtle movement logic.

---

## How to Run This Project

1. Clone this repository:
   ```bash
   git clone https://github.com/CodingWorld-007/PythonTurtle-RamJii.git
   ```

2. Make sure the file `Shree_ram.gif` is in the same folder as `Ramjii.py`

3. Run the Python file:
   ```bash
   python Ramjii.py
   ```

4. Click on the button area on the screen to start the animation.
